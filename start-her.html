🚀 Start her – Ny i Python

Her begynner du å lære Python fra starten. Du trenger ingen erfaring med programmering. Les en forklaring, skriv koden selv og test hva som skjer.

📘 Åpne Lær Python

1. Din første Python-kode

Gå til Lær Python og start med den første leksjonen. Finn ut hvordan print() brukes til å vise tekst.

Prøv selv: Få Python til å skrive ut en hilsen. Endre teksten til noe du velger selv.

Start å lære Python

2. Variabler

Fortsett i Lær Python. Lær hvordan et navn kan brukes til å huske tekst eller tall.

Prøv selv: Lag en variabel for navnet ditt, og skriv den ut.

3. Spørsmål og svar

Utforsk hvordan input() lar et program spørre brukeren om noe.

Prøv selv: Lag et program som spør om navn og svarer med en hilsen.

4. Valg i programmer

Lær hvordan if gjør at programmet kan velge hva som skal skje.

Prøv selv: Lag et program som gir ulike svar avhengig av hva brukeren skriver.
